## 如何使用练习题

### 推荐学习顺序

1. **先独立思考**：每道题先自己想 10-15 分钟，尝试写出代码
2. **参考提示但不要抄**：提示是帮助你突破瓶颈，不是让你直接复制
3. **验证答案**：完成后用 `go run` 验证代码是否能正常运行
4. **对比参考解法**：看看自己的解法和参考解法有什么不同

### 练习题结构

每道练习题包含：
- **题目**: 描述要解决的问题
- **目标**: 练习后应该掌握什么
- **输入输出示例**: 帮助你理解预期行为
- **提示**: 提供解题思路，但不给出完整答案
- **参考解法路径**: 说明应该朝哪个方向思考

## 如果遇到困难

1. **回到课程**: 如果某道题完全没思路，说明相关课程内容没理解透，回去重读 README
2. **查阅官方文档**: Go 的标准库文档非常完善，尝试直接读文档
3. **写小实验**: 如果不确定某个语法行为，写一个小程序实验它
4. **借助 AI**: 可以让 AI 给你提示，但不要让它直接给你答案
